# 匿名用户精准广告投放生态系统

## 项目简介
一个多系统协作的匿名用户精准广告投放平台，实现跨网站的匿名用户行为追踪与精准广告投放。系统包含四个独立部署的子系统，通过统一的API接口进行广告管理和投放。

## 系统架构

### 核心组件
1. **广告管理平台** - 广告商发布和管理广告
2. **购物网站** - 展示商品并采集用户行为
3. **视频分享网站** - 支持视频广告插播
4. **新闻门户网站** - 内容浏览与广告展示

### 技术特点
- 🎯 **匿名用户精准投放** - 基于浏览行为，无需用户登录
- 📱 **多格式广告支持** - 文字、图片、视频广告
- 🎬 **智能广告插播** - 视频前中后贴片广告
- 🔄 **实时行为追踪** - 跨网站用户行为分析
- 🚀 **分布式部署** - 四个系统独立部署
